* 
* Clear Mode (Physical Showcasing): When the computer is idle, the diamond dust particles sit perfectly aligned within the quartz lattice. Light travels through unobstructed, acting as a crystal-clear, museum-grade glass window that allows a flawless view of the enclosed physical card.
* Dark/Screen Mode (The Transformation): When a user triggers an interaction, the Tesla coil core pulses. The internal electrons are driven directly into the diamond dust carbon bonds, temporarily shifting a localized layer into a Carbon Graphene Film. Graphene is naturally dark, highly conductive, and acts as a hyper-fast electronic canvas. [2] 
* The Screen Matrix: This shifting graphene film instantly acts as an ultra-high-definition screen capable of displaying movies, streaming media, or interactive graphics over the card without requiring a separate LCD panel.
